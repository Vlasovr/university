### 1.4. Cat.5e против Cat.6 для 1000BASE-T и 2.5GBASE-T

- 1000BASE-T (IEEE 802.3 Clause 40) рассчитан на канал класса D (Cat.5e) длиной до 100 м — Cat.5e достаточно.
- 2.5GBASE-T/5GBASE-T (IEEE Std 802.3bz-2016, утверждён IEEE-SA 22.09.2016; текст на странице целевой группы: https://www.ieee802.org/3/bz/). Утверждённые цели проекта (файл https://www.ieee802.org/3/bz/ngeabt_objectives_802.3WG_approved_0315.pdf, прочитан): «Define a 2.5 Gb/s PHY for operation over up to at least 100 m on four-pair Class D (Cat5e) balanced copper cabling»; «Define a 5 Gb/s PHY … up to at least 100 m on four-pair Class E (Cat6) … [и] up to 100 m on four-pair Class D (Cat5e) on defined use cases and deployment configurations». То есть 2.5GBASE-T на Cat.5e до 100 м поддерживается стандартом; 5GBASE-T на Cat.5e — только для «определённых сценариев» (ограничения по alien crosstalk), гарантированно — на Cat.6.
- Разница в цене по рынку РБ (медь, PVC, 305 м): Cat.5e мин. 260 BYN против Cat.6 мин. 491 BYN (оба ExeGate CU) — Cat.6 дороже примерно в 1,9 раза. Для линий ≤25 м и Gigabit/2.5G запас Cat.6 не нужен; бюджетное решение — Cat.5e медь.
- Наружный диаметр (для расчёта сечения короба), по техническому описанию ITK (сниппет поиска по документам cdn-01.iek.ru, сам PDF не открылся): U/UTP кат.5e 4×2×24 AWG — 5,2 ± 0,2 мм; F/UTP кат.5e — 6,0 ± 0,2 мм; Cat.6 U/UTP 23 AWG — обычно 6,0–6,5 мм (значение производителя не подтверждено, проверить в паспорте выбранной бухты). Минимальный радиус изгиба — 10 наружных диаметров (ITK), т.е. ~52 мм для U/UTP 5e.

### 1.5. Медь против CCA и почему CCA нельзя для PoE

- ISO/IEC 11801-1 и ANSI/TIA-568.2 задают требования к сопротивлению постоянному току проводника (для кат.5e/6 — не более 9,38 Ом на 100 м для жилы 24 AWG) и подразумевают медную жилу; CCA (алюминий с медным покрытием) имеет сопротивление примерно на 40–55 % выше, поэтому бухта CCA не соответствует категории по DC-сопротивлению и не проходит сертификацию Fluke по постоянному току/вносимым потерям на длинных линиях. (Конкретные пункты стандартов в этой сессии онлайн не проверены — ссылки на TIA/ISO ниже.)
- IEEE 802.3 Clause 33 (PoE) нормирует сопротивление петли канала (для Type 1 — до 25 Ом, для Type 2 — до 12,5 Ом; по памяти, проверить по тексту стандарта). CCA превышает это сопротивление, что даёт падение напряжения и нагрев жил, особенно в пучке в коробе; при 802.3at (25,5 Вт) и 802.3bt нагрев CCA опасен — сторонние ассоциации (CCCA, Fluke Networks) прямо не рекомендуют CCA для PoE. Для курсового: писать «в проекте применяется кабель с жилой из чистой меди (CU) по требованию ISO/IEC 11801-1 и для обеспечения PoE 802.3af/at».
- Белорусские производители LAN-кабеля: сайты beltelecable.by и belaruskabel.by из среды исследования недоступны (DNS/отказ), наличие в розничных каталогах бухт кат.5e белорусского производства не подтверждено. Белорусский производитель, подтверждённый по кабель-каналам: Bylectrica (УП «Светоприбор» ОО «БелТИЗ», Минск).

## 10. Методики расчёта (источники для цитирования)

### 10.1. Длина кабеля горизонтальной подсистемы

Метод суммирования/усреднения из практики проектирования СКС (ISO/IEC 14763-2 и TIA рекомендуют расчёт по трассам; формула среднего значения в русскоязычной литературе):

L_ср = (L_max + L_min) / 2 × K_s + X,

где L_max, L_min — наибольшая и наименьшая длина трасс от шкафа до розетки по плану, K_s = 1,1 — коэффициент технологического запаса (изгибы, обход препятствий), X — запас на разделку с двух сторон (обычно 1–2 м, в литературе также встречается 1 м при точном трассировании). Число линий из одной бухты: N = floor(305 / L_ср); число бухт: ceil(N_линий / N).

Источники:
- Семёнов А. Б., Стрижаков С. К., Сунчелей И. Р. Структурированные кабельные системы. 5-е изд. — М.: АйТи; ДМК Пресс, 2004 (глава о проектировании горизонтальной подсистемы, формула средней длины).
- Семёнов А. Б. Проектирование и расчёт структурированных кабельных систем и их компонентов. — М.: ДМК Пресс, 2003.
- ISO/IEC 14763-2:2019 Information technology — Implementation and operation of customer premises cabling — Part 2: Planning and installation (страница ISO из среды исследования не открылась; номер стандарта известен).
- ГОСТ Р 53246-2008 (раздел проектирования горизонтальной подсистемы) — как методический источник с пометкой о статусе.

Пример для проекта (на здание): L_max = 25 м, L_min = 5 м → L_ср = 15 × 1,1 + 2 = 18,5 м; N = floor(305/18,5) = 16 линий из бухты; при 10 линиях — одна бухта на здание с остатком ~120 м (запас на точку доступа/переделки).

### 10.2. Покрытие Wi-Fi: потери в свободном пространстве

Рекомендация ITU-R P.525-5 (11/2024), уравнения (5)–(6) (текст PDF прочитан): L_bf = 20 lg(4πd/λ) дБ; в практических единицах L_bf = 32,4 + 20 lg f + 20 lg d, где f — МГц, d — км (эквивалентно 32,44 + 20 lg f[МГц] + 20 lg d[км] или −27,55 + 20 lg f[МГц] + 20 lg d[м]).

Пример: f = 2437 МГц, d = 10 м: L_bf = 32,4 + 67,7 − 40 ≈ 60,1 дБ; f = 5200 МГц, d = 10 м: ≈ 66,7 дБ. Бюджет линии: P_rx = P_tx + G_tx + G_rx − L_bf − Σ потерь на перегородки (гипсокартон 3–5 дБ, кирпич 6–10 дБ, по ITU-R P.2040/P.1238 — не проверялось в этой сессии). Целевой уровень для 802.11ax: ≥ −65 дБм для MCS высоких порядков, ≥ −70 дБм на границе зоны. Для одноэтажного здания 60–100 м² одна ТД в центре с запасом.

Ссылки: https://www.itu.int/rec/R-REC-P.525/en ; PDF: https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.525-5-202411-I!!PDF-E.pdf ; для индор-модели — ITU-R P.1238 (Propagation data and prediction methods for the planning of indoor radiocommunication systems).
